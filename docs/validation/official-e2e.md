# Official 通道 e2e 验证清单

> 目的：**用证据决定能不能解锁**，而不是用感觉。
> 每条都要求「操作 → 预期 → 证据位置」，全绿才允许合并回主仓库。

前置：

- [ ] 主仓库版本 >= 0.4.29（三个缺口已修）
- [ ] `config.json`：`official.enabled: true`、`appid`、`secret`、`allowAll: false`、`allow: [<测试群 openid>]`
- [ ] `official.ownerOpenid` = 你自己的 openid（从日志 `[official] 进入处理：… openid=xxxxxx…` 取）
- [ ] 桥接已重启，日志出现 `[official] 已就绪，开始收群/单聊消息`
